# دليل إنقاذ ورعاية النباتات المنزلية

منتج رقمي تفاعلي (موقع ويب) لرعاية النباتات المنزلية. اللغة عربية مصرية، والاتجاه من اليمين لليسار.

المرحلة الحالية: **المرحلة 1** — الصفحة الرئيسية، دليل النباتات، وصفحة كل نبات، وأماكن أدوات العناية الجاية.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000).

لبناء نسخة الإنتاج:

```bash
npm run build
npm start
```

## الملاحظات

- مفيش قاعدة بيانات ولا تسجيل دخول ولا دفع في المرحلة دي.
- بيانات النباتات موجودة في ملفات TypeScript تحت `data/`.
- أدوات التشخيص لسه ظاهرة كـ «قريبًا» من غير وظائف وهمية.
